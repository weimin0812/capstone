Course outline
This capstone course consists of five comprehensive modules. We recommend setting aside approximately 14 hours to complete all modules successfully. Consistent progress will help you achieve your learning goals and produce a portfolio-ready generative AI solution.

To get the most out of this experience, complete the hands-on labs and apply your skills to the real-world restaurant recommendation scenario that drives this capstone project. Each lab includes an introductory reading that explains the objectives and tasks, helping you approach the exercises with clarity and context.

Module 1: Build a Structured Generative AI Application 
In this module, you’ll use large language models (LLMs) to transform unstructured restaurant descriptions into structured JSON files by designing prompts and extracting predefined attributes. You will apply multimodal LLMs to generate captions from review images and integrate those captions into structured user review data.

Finally, you’ll build a command-line Python interface to browse, add, edit, and delete restaurant records, integrate LLM-powered structuring functions for new entries, and implement file backup mechanisms before saving updates.

Module 2: Design a Multimodal RAG System
In this module, you will design and implement the retrieval layer of a multimodal RAG system using structured restaurant text data and food images. You will construct multimodal vector indexes, generate text and image embeddings, and develop retrieval workflows that combine similarity search with metadata-based filtering. You will also implement late-fusion multimodal similarity fusion and ranking methods to improve cross-modal ranking behavior across heterogeneous data sources. The module follows a production-style retrieval pipeline that progresses from index construction to hybrid similarity retrieval and late-fusion ranking. The module emphasizes retrieval pipeline design and ranking methods rather than framework-specific features. 

Module 3: Combine Agents into a Multi-Agent System
In this module, you will design and implement a multi-agent recommendation system. You will define specialized agents with clear roles, goals, backstories, and tasks, then integrate them into a coordinated multi-agent workflow. You will implement and test how multiple agents work together to generate restaurant and recipe recommendations from a single user input. 

You will then build an interactive chatbot interface using Gradio to expose the multi-agent system. The chatbot will process user queries related to restaurants or specific foods, display coordinated agent outputs, and support basic database editing functionality within the interface.

Module 4: Integrate Agents, RAG, and Tools with MCP
In this module, you’ll organize agent tools, databases, and documents within an MCP server. You will then build an MCP client and an LLM-based MCP host that communicate with the server and validate the system through testing. You will also design and implement an LLM-powered MCP host with a GUI that allows the LLM to access server-exposed tools and documents. This module brings together the components built earlier into a single MCP-based setup and validates end-to-end tool execution through a GUI-based host application. 

Module 5: Final Project and Course Wrap-Up
In this module, you will complete your AI capstone project by submitting screenshots or links to tasks performed in previous labs. You’ll organize and present these artifacts to clearly demonstrate how you designed, built, and integrated structured data, multimodal RAG systems, and multi-agent workflows using LangChain, LangGraph, and MCP. This submission will serve as a final evaluation through an AI-based grading system and provide a portfolio-ready showcase of your end-to-end generative AI solution.
